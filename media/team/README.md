# Team photos (private — not committed)

Everything in this folder is **git-ignored** except these placeholders, on
purpose: real photos of staff should not end up in a public repository.

## How to use

1. Drop each team member's photo here as a normal image file
   (`.jpg`, `.png`, or `.svg`).
2. Point to it from [`content/team.yaml`](../../content/team.yaml) with the
   `photo:` field (just the file name, e.g. `photo: "alex.jpg"`).
3. Square images (e.g. 400×400) look best in the 4-quadrant "meet the team"
   slide.

The repo ships with `placeholder-1.svg` … `placeholder-4.svg` so the slide
works out of the box before you add real photos.

> **Privacy:** only use photos of the adult staff, with their permission.
> Never add images of children.
