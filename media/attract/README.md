# Attract-mode media (drop-ins — not committed)

Anything you put in this folder is shown in the monitor's **attract mode**
(the loop that plays when nobody has tapped the iPad for 45 seconds).

Supported files:

- **Images:** `.jpg`, `.png`, `.gif`, `.svg`, `.webp`
- **Videos:** `.mp4`, `.webm` (played muted, then the loop moves on)

Ideas:

- Export a Google Slide as a PNG and drop it here.
- Add a short AI-avatar video introducing the table.
- Add your school or company logo.

Files here are **git-ignored** (they can be large or private), so the folder
ships empty except for this README. The monitor picks up whatever is present
when the page loads.
